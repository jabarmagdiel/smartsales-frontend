# Instalación de Dependencias para Gráficas

Para que funcionen las gráficas del módulo de IA, ejecuta estos comandos en el directorio del frontend:

```bash
npm install react-chartjs-2 chart.js
```

O si usas yarn:

```bash
yarn add react-chartjs-2 chart.js
```

Estas librerías son necesarias para:
- CU24: Visualizar Predicciones en Dashboard
- CU25: Visualizar Ventas Históricas (Gráficas)
- CU26: Monitorear Estado del Modelo

Las gráficas incluyen:
- Gráficas de barras para predicciones por producto
- Gráficas de dona para importancia de características
- Visualizaciones interactivas del estado del modelo
